## 3. ライセンス API フロー（要約）

1. ユーザーが購入 → メールで `license_key`
2. フロントの入力 or URL `?license_key=` → `POST .../licenses/activate`
3. 成功レスポンスの `instance.id` を localStorage に保存
4. 以降の起動で validate → `status === active` なら Pro
5. `variant_id` を env と照合し偽装防止

`instance_name` 例: `Chord_Palette_Client_Web`

## 6. 3 大コード進行（動画演出用）

### J-POP 王道（4-5-3-6）Key=C

`F → G → Em → Am`  
演出: 3 秒サイン波ルート単音（Before）→ Chord Palette UI + テンション付きエレピ（After）

### チル系 Key=C

`F△7 → C△7 → E/F# → Em/A`  
BPM 70–80、Lo-Fi ドラム薄く、コード切替にハミング/五線譜オーバーレイ

### 丸サ進行（Just the Two of Us 系）Key=C

`Fmaj7 → E7 → Am7 → Gm7 → C7`  
フック: E7 の G#（セカンダリードミナント）、Gm7 モーダルインターチェンジ解説
