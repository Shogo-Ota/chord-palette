# Chord Palette v2.3

## 概要

Chord Palette はモバイル特化のコード進行スケッチツール。v2.3 では UI の洗練化、画面録画時の音声安定化、コード選択 UI の整理、初見ユーザー向け UX を追加し、より多くの作曲家・ミュージシャンが使えるプロダクトへブラッシュアップする。

## ターゲットユーザー

- スマホで素早くコード進行を試したい作曲家・ミュージシャン
- 画面録画で進行を共有したいクリエイター
- 音楽理論の知識はあるが、DAW ほど重いツールは不要なユーザー

## 機能一覧

| 優先度 | 機能 |
|---|---|
| 高 | 再生コントロール UI 再設計（Header 集約 + playback-bar） |
| 高 | 画面録画時の音声安定化 |
| 高 | バリエーションツールバー化（6/sus/テンション外だし） |
| 高 | 進行の localStorage 永続化 |
| 高 | 初回オンボーディング |
| 高 | 進行コピー共有 |
| 高 | UI ラベル日本語統一 |
| 中 | PWA 対応 |
| 中 | 履歴表示改善 |
| 中 | TheoryExplainer API 未設定時非表示 |
| 低 | 短調対応（v2.4） |
| 低 | URL パラメータ共有（v2.4） |

## 技術スタック

- React 19 + TypeScript + Vite 8
- TailwindCSS v4 + index.css カスタム CSS
- Framer Motion 12
- Web Audio API（自前 audioEngine）
